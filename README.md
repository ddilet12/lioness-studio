# Lioness Edit

Воссоздай сайт В ТОЧНОСТИ по прикреплённому изображению-референсу.

КРИТИЧЕСКИ ВАЖНО:

Не придумывай новый дизайн.

Не улучшай дизайн на своё усмотрение.

Не меняй композицию.

Не меняй порядок блоков.

Не меняй типографику, размеры, отступы, цвета и визуальную иерархию без необходимости.

Референс является главным источником дизайна. Твоя задача — максимально точно повторить его как полноценный production-ready сайт.

Сайт должен выглядеть так, будто изображение-референс является скриншотом уже существующего сайта.

BRAND:

Название бренда: LIONESS DRESS

Логотип: LD

Позиционирование: luxury women's fashion / premium evening dresses.

Визуальный стиль: luxury editorial fashion, минимализм, Paris/Astana aesthetic, premium magazine.

==================================================

1. ОБЩАЯ СТИЛИСТИКА

==================================================

Используй:

- премиальный fashion editorial стиль

- большое количество свободного пространства

- cream / ivory background

- чёрный текст

- тёмный почти чёрный footer

- небольшие красные акценты

- serif typography для крупных заголовков

- аккуратный минималистичный sans-serif для навигации

- тонкие линии

- маленькие uppercase подписи

- фотографии большого формата

- очень аккуратную сетку

- отсутствие лишних декоративных элементов

Главное ощущение:

HIGH-END FASHION BRAND / LUXURY EDITORIAL / QUIET LUXURY.

Не использовать:

- градиенты

- яркие современные UI-карточки

- стеклянные эффекты

- неон

- массивные кнопки

- стандартные шаблонные ecommerce-компоненты

- чрезмерные border-radius

- дешёвый startup-style дизайн.

==================================================

Структура:

LD

На мобильных устройствах сохрани визуальную эстетику, но адаптируй меню через аккуратное hamburger menu.

==================================================

Hero занимает практически весь первый экран.

Композиция фотографии должна соответствовать референсу:

- женщина находится преимущественно в центре/левой части

- чёрное платье

- справа находится светлая luxury shopping bag с логотипом LD

- background — beige luxury airplane interior

- фотография должна занимать весь hero

- image должен быть cinematic

- luxury editorial fashion photography

PARIS 2026

Большой заголовок:

BLACK

ANGEL

тонкая горизонтальная линия и небольшие metadata элементы.

Hero должен иметь затемнение/градиент только настолько, насколько необходимо для читаемости текста, но фотография должна оставаться естественной.

Высота hero: примерно 100vh.

9. TYPOGRAPHY

==================================================

Очень важно подобрать максимально похожую типографику.

Для крупных заголовков использовать elegant high-fashion serif font.

Подходящие варианты:

Cormorant Garamond

Playfair Display

Bodoni Moda

DM Serif Display

Для навигации, подписей, цен и маленького текста:

Inter

Helvetica Neue

Arial

или другой очень чистый grotesk sans-serif.

Большие заголовки должны иметь:

- высокий контраст

- тонкие линии

- editorial fashion appearance

- tight but elegant line-height.

==================================================

10. SPACING

==================================================

Не делай сайт плотным.

Используй большие vertical margins.

Каждый блок должен ощущаться как страница luxury fashion magazine.

Desktop:

максимальная ширина контента около 1400px.

Основные horizontal margins:

примерно 30–50px.

==================================================

11. АДАПТИВНОСТЬ

==================================================

Сайт должен идеально работать:

Desktop

Tablet

Mobile

На мобильном:

- hero остаётся full-screen

- изображение правильно crop-ится

- заголовок BLACK ANGEL остаётся крупным

- New arrivals превращается в horizontal swipe carousel либо 2-column grid

- Story section становится вертикальным

- footer становится вертикальным

- никаких горизонтальных overflow

- никаких сломанных изображений

- typography автоматически масштабируется.

==================================================

12. АНИМАЦИИ

==================================================

Добавь очень деликатные premium animations.

При загрузке:

- плавное появление hero image

- плавное появление текста

- небольшое движение текста вверх

- header появляется плавно

При scroll:

- fade-up для текстовых блоков

- очень лёгкий parallax для больших фотографий

- плавное появление product cards

- image hover zoom 1.03–1.05

- плавные transitions 400–800ms

ВАЖНО:

Анимации должны выглядеть как luxury fashion website.

Не использовать чрезмерные bounce effects или стандартные UI animations.

==================================================

14. E-COMMERCE

==================================================

Сайт должен быть не просто картинкой.

Создай рабочую структуру:

- product cards

- product detail pages

- Add to bag

- shopping bag

- quantity selector

- product filtering

- responsive navigation

Но визуально всё должно оставаться в стиле референса.

==================================================

15. IMAGE GENERATION / PLACEHOLDERS

==================================================

Если реальные изображения отсутствуют, используй качественные fashion-editorial изображения или image placeholders, максимально соответствующие референсу.

Все изображения должны иметь:

- luxury fashion photography

- cinematic lighting

- neutral beige / black palette

- premium editorial composition

- realistic photography

- high-end campaign aesthetic.

НЕ используй дешёвые stock-photo изображения.

==================================================

16. ФИНАЛЬНОЕ ТРЕБОВАНИЕ

==================================================

Ещё раз:

ИЗОБРАЖЕНИЕ-РЕФЕРЕНС = SOURCE OF TRUTH.

Не делай "похожий сайт".

Сделай максимально точную визуальную реконструкцию.

Сохрани:

- структуру

- порядок секций

- размеры блоков

- пропорции

- whitespace

- типографику

- цвета

- расположение текста

- расположение изображений

- header

- product grid

- campaign image

- story section

- footer.

После реализации сравни результат визуально с референсом и самостоятельно исправь все заметные отличия.

Цель: при сравнении screenshot созданного сайта и исходного изображения они должны выглядеть практически идентично.
